# ค่าความถูกต้องของคำตอบ วัดโดยผู้ประเมินสามคน

ผู้ประเมินสามคนอ่านคำตอบชุดเดียวกัน 60 ข้อ (30 หัวข้อ × ถามตรงตัวบท/ถามด้วยภาษาพูด)
เทียบกับตัวบทใน `data/processed/corpus_ksp.jsonl` ทุกข้อ ไม่ตัดสินจากความจำ

เก็บคำตอบครั้งเดียวต่อรอบด้วย `ingest.collect_answers` เพราะผู้ให้บริการโมเดล
ไม่รองรับ seed — เรียกสามครั้งที่ temperature 0 ได้คำตอบต่างกันสองแบบ ถ้าให้
ผู้ประเมินแต่ละคนถามเอง ระยะห่างระหว่างคนจะวัดผู้ให้บริการ ไม่ใช่วัดผู้ประเมิน

## วิธีวัดรอบต่อไป

```
.venv/bin/uvicorn app.main:app --port 8077 &
.venv/bin/python -m ingest.collect_answers          # -> data/eval/user_answers.json
cp data/eval/user_answers.json data/eval/user_answers_roundN.json
```

แล้วให้ผู้ประเมินสามคนอ่าน `data/eval/review_packet_roundN_1..4.md` — แฟ้มนี้
มีคำถาม คำตอบ และตัวบทคำต่อคำของทุกข้อที่คำตอบอ้าง พร้อมหมวดที่ข้อนั้นอยู่
ผู้ประเมินไม่ต้องเปิดคลังเอง ทำแฟ้มด้วยสคริปต์ที่แยกการอ้างอิงจากคำตอบด้วย
regex แล้วดึงตัวบทมาวางไว้ข้าง ๆ

เขียนผลเป็น `data/eval/coding_roundN_assessor{1,2,3}.json` แล้วรวมตารางด้วย
`.venv/bin/python -m ingest.score_assessors` (สคริปต์อ่านชื่อไฟล์แบบ
`coding_assessorN.json` ต้อง copy หรือแก้ชื่อก่อน)
