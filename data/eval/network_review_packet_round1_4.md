# แฟ้มประเมินชุดเครือข่าย รอบ 1 ส่วนที่ 4

## เกณฑ์การให้รหัส

รหัส 1 ถามด้วยคำของหนังสือ และคำตอบถูกต้อง
รหัส 0 ถามด้วยคำของหนังสือ และคำตอบไม่ถูกต้อง
รหัส 2 ถามด้วยภาษาพูด (กำกวม) และคำตอบถูกต้อง
รหัส 3 ถามด้วยภาษาพูด (กำกวม) และคำตอบไม่ถูกต้อง

ลักษณะคำถาม (ตรง/กำกวม) กำหนดไว้แล้วในแต่ละข้อ ผู้ประเมินตัดสินเฉพาะว่าคำตอบถูกหรือไม่ถูก

นับว่าไม่ถูกต้องเมื่อ
- กล่าวสิ่งที่ขัดกับข้อความในหนังสือ
- สาระหลักของคำตอบอ้างบทและหน้าที่ไม่มีข้อความนั้น หรือหนังสือไม่ได้เขียนไว้เลย
- เติมตัวเลข ชื่อมาตรฐาน ชื่อเมนู ชื่อปุ่ม หรือขั้นตอนที่หนังสือไม่ได้เขียน ลงในส่วนที่อ้างหนังสือ
- แจกแจงไม่ครบเมื่อคำถามถามว่ามีอะไรบ้าง หรือขั้นตอนขาดจนทำตามไม่ได้ หรือเรียงลำดับผิด
- ตอบเรื่องอื่นที่ไม่ใช่เรื่องที่ถาม
- ปฏิเสธ หรือตอบจากความรู้ทั่วไปของ AI (ขึ้นต้นว่าหนังสือไม่ได้อธิบายไว้ หรือยืนยันกับหนังสือไม่ได้)
  ทั้งที่หนังสือมีคำตอบ

นับว่าถูกต้องเมื่อ
- สาระถูก และบทกับหน้าที่อ้างมีข้อความนั้นจริง
- สำนวนไม่สวย ข้อความถูกตัดตามความยาวที่จำกัด คำสะกดผิดที่ติดมาจากหนังสือ
  หรือมีรายละเอียดที่ถูกต้องเพิ่มมา ไม่นับเป็นข้อผิด
- ส่วนใต้ป้าย "💡 เสริมจากความรู้ทั่วไปของ AI" ไม่ต้องมีในหนังสือ นับผิดเฉพาะเมื่อเป็นข้อเท็จจริงที่ผิดชัดเจน

เกณฑ์ผ่าน: ผู้ประเมินทุกคนต้องได้ค่าความถูกต้องไม่น้อยกว่า 80%

## N-23b (ลักษณะคำถาม: กำกวม, บทที่ 5)

**คำถาม** อยากให้แผนกหนึ่งเปิดโฟลเดอร์ได้ แต่อีกแผนกเข้าไม่ได้ ต้องตั้งค่ายังไง

**ที่มาของคำตอบ** book (ตอบ)

**คำตอบ**

ต้องตั้งค่าสิทธิ์ (Permission) ให้โฟลเดอร์เฉพาะกลุ่มแผนกที่ต้องการให้เข้าถึงเท่านั้น โดยสร้างกลุ่มแผนกคอมพิวเตอร์และแผนกการตลาดแยกกัน จากนั้นกำหนดสิทธิ์ให้โฟลเดอร์ job\_computer เปิดให้เฉพาะกลุ่มแผนกคอมพิวเตอร์เข้าถึงได้แบบเต็มสิทธิ์ ขณะที่โฟลเดอร์ job\_marketing เปิดให้เฉพาะกลุ่มแผนกการตลาดเข้าถึงได้แบบเต็มสิทธิ์ (บทที่ 5 หน้า 208)
• สร้างโฟลเดอร์ย่อยในโฟลเดอร์ DATA\_CENTER ชื่อ job\_computer และ job\_marketing ตามลำดับ (บทที่ 5 หน้า 191-192)
• คลิกขวาที่โฟลเดอร์ job\_computer เลือก Properties → แท็บ Security → Edit → Add → Advanced → Find Now → ดับเบิลคลิกที่ Department of Computer → ตั้งสิทธิ์ Full control → OK (บทที่ 5 หน้า 193-197)
• เปิดแชร์โฟลเดอร์โดยไปที่แท็บ Sharing → Share... → เลือกแผนกคอมพิวเตอร์ → ตั้งสิทธิ์ Read/Write → Share → Done
• ทำลักษณะเดียวกันกับโฟลเดอร์ job\_marketing แต่ให้สิทธิ์เฉพาะกลุ่มแผนกการตลาด (บทที่ 5 หน้า 197-200)
• โฟลเดอร์ที่ต้องการให้ทุกคนเข้าถึงได้ ให้ตั้งสิทธิ์ Read เท่านั้น (บทที่ 5 หน้า 193-197)

**รูปที่แนบ** 12. ลำดับถัดไป ให้ดำเนินการในลักษณะเดียวกันนี้ ด้วยการเพิ่มยูสเซอร์ somsak และ somyod เข้าเป็นสมาชิกสังกัดแผนกการตลาด / 1. ที่เครื่อง COMPUTER1 เปิดหน้าต่าง Computer ขึ้นมา คลิกที่ไดรฟ์ C: และ สร้างโฟลเดอร์ DATA_CENTER ดังรูป / 2. ภายในโฟลเดอร์ DATA CENTER ให้สร้างโฟลเดอร์ย่อย ดังนี้ job_computer, job_marketing และ notice

การกำหนดเวิร์กกรุ๊ปบนเครื่อง COMPUTER3 ที่ใช้ Windows 8 ทำได้ดังนี้

## N-25b (ลักษณะคำถาม: กำกวม, บทที่ 6)

**คำถาม** เครื่องวินโดวส์ 8 จะเอาเข้าเวิร์กกรุ๊ปเดียวกับเครื่องอื่นต้องทำไง

**ที่มาของคำตอบ** book (ตอบ)

**คำตอบ**

เครื่อง Windows 8 สามารถเข้าร่วมเวิร์กกรุ๊ปเดียวกับเครื่องอื่นได้ โดยต้องตั้งค่าให้เครื่องนั้นมีชื่อเวิร์กกรุ๊ปเหมือนกันกับเครื่องอื่นในเครือข่ายเดียวกัน (บทที่ 4 หน้า 130-131)
1. ให้คลิกขวาที่ไอคอน My Computer แล้วเลือก Properties
2. คลิกที่ปุ่ม Change ภายใต้ Computer description
3. ตั้งชื่อคอมพิวเตอร์และกำหนดชื่อเวิร์กกรุ๊ปให้ตรงกับเครื่องอื่น เช่น STAFF
5. คลิก Yes เพื่อบูตเครื่องใหม่ (บทที่ 6 หน้า 244-246)

เมื่อบูตเครื่องใหม่แล้ว เครื่อง Windows 8 จะเข้าร่วมเวิร์กกรุ๊ปเดียวกันกับเครื่องอื่นได้ (บทที่ 6 หน้า 259)

**รูปที่แนบ** 1. ที่เครื่อง COMPUTER4 ให้ล็อกออนเข้าระบบด้วยบัญชี Computer#4 จากนั้น ให้คลิกขวาที่ไอคอน My Computer แล้วเลือกรายการ Properties / 2. กรอกรายละเอียดตรง Computer description ลงไป จากนั้นคลิกปุ่ม Change / 3. เพื่อเป็นไปตามข้อกำหนด จึงตั้งชื่อคอมพิวเตอร์เครื่องนี้ว่า COMPUTER4 ต่อ ไปคลิกที่ Workgroup และกำหนดชื่อเวิร์กกรุ๊ปว่า STAFF แล้วคลิกปุ่ม OK / 4. ภาพแสดงข้อความยินดีเข้าสู่เวิร์กกรุ๊ป STAFF ให้คลิกปุ่ม OK / 5. จะมีข้อความแจ้งเตือนว่า จะต้องบูตเครื่องใหม่ เพื่อให้ค่าที่ติดตั้งไว้มีผล ให้ คลิกปุ่ม OK / 6. คลิกปุ่ม Yes เพื่อบูตเครื่องใหม่ / 1. คลิกที่ปุ่ม Start > Control Panel > Network Connections จากนั้นคลิกขวา ตรงไอคอน Local Area Connection แล้วเลือกรายการ Properties

1. เปิดไฟล์ดังกล่าวขึ้นมาแบบอ่านได้อย่างเดียว
2. สร้างไฟล์สำเนาขึ้นมาเพื่อใช้งานในเครื่องของตน แล้วนำไปรวมกันเองภายหลัง
3. เปิดไฟล์แบบอ่านได้อย่างเดียวไปก่อน แล้วรอแจ้งเตือนการปลดล็อกไฟล์ (บทที่ 7 หน้า 288)

## P55 — บทที่ 2 ช่องทางการสื่อสารและส่วนประกอบของเครือข่าย — หัวข้อ ส่วนประกอบเครือข่าย (หน้า 64)

5. ซอฟต์แวร์เครือข่าย ซอฟต์แวร์เครือข่ายในที่นี้หมายรวมถึงโปรแกรมระบบปฏิบัติการและโปรแกรมอรรถประโยชน์ที่ใช้งานบนเครือข่าย ซึ่งโดยปกติเครื่องคอมพิวเตอร์ทุกๆ เครื่องบนเครือข่ายจำเป็นต้องติดตั้งโปรแกรมระบบปฏิบัติการเช่นเดียวกับเครื่องพีชีตั้งโต๊ะที่ใช้งานทั่วไป

รูปที่ 2.32 ระบบปฏิบัติการเครือข่าย Windows Server 2008 และ 2012 ระบบปฏิบัติการบนเครื่องลูกข่าย สำหรับระบบปฏิบัติการบนเครื่องลูกข่ายจำเป็นต้องคอนฟิกระบบหรือติดตั้งโปรแกรมเพื่อให้สามารถเชื่อมโยงกับเครื่องเชิร์ฟเวอร์ได้ ระบบปฏิบัติการบนเครื่องลูกข่ายอาจเป็นระบบปฏิบัติการคนละตัวกับเครื่องแม่ข่ายหรือเครื่องเซิร์ฟเวอร์ก็เป็นได้ แต่ทั้งนี้ในกรณีตังกล่าว อาจจำเป็นต้องติดตั้งชุดติดตั้งเครื่องลูกข่ายโดยเฉพาะ รวมถึงการคอนฟิกระบบและกำหนดชนิดโปรโตคอลที่ใช้งานให้ตรงกัน ตัวอย่างเช่น เครื่องเซิร์ฟเวอร์เป็น Windows Server 2012 และเครื่องลูกข่ายเป็น Windows 7, Windows 8 หรือเครื่องเซิร์ฟเวอร์เป็น Unix และเครื่องลูกข่ายใช้ระบบปฏิบัติการ Windows เป็นต้น

## P56 — บทที่ 2 ช่องทางการสื่อสารและส่วนประกอบของเครือข่าย — หัวข้อ ส่วนประกอบเครือข่าย (หน้า 65)

โปรแกรมอรรถประโยชน์ที่ใช้งานบนเครือข่าย ปัจจุบันมีโปรแกรมอรรถประโยชน์ (Utlities Program) จำนวนมากมายที่สามารถนำมาใช้งานบนเครือข่ายเพื่อเพิ่มประสิทธิภาพการทำงานให้สูงขึ้น ตัวอย่างเช่น โปรแกรมไฟร์วอลล์ โปรแกรมช่วยการสำรองข้อมูลบนเครือข่าย หรือโปรแกรมป้องกันไวรัสคอมพิวเตอร์ เป็นต้นโปรแกรมอรรถประโยชน์ที่ใช้งานบนเครือข่ายจะปฏิบัติงานอยู่เบื้องหลังและสนับสนุนงานต่างๆ ในขณะที่เครือข่ายกำลังทำงานอยู่ โปรแกรมอรรถประโยชน์ที่ใช้งานบนเครือข่าย โดยพื้นฐานทั่วไปแล้วมักผนวกมาพร้อมกับชุดติดตั้งระบบเครือข่าย แต่สำหรับกรณีชุดโปรแกรมอรรถประโยชน์ที่ทำงานเฉพาะด้าน อาจจำเป็นจะต้องแยกซื้อต่างหาก ตัวอย่างกลุ่มโปรแกรมอรรถประโยชน์ที่ใช้งานบนเครือข่าย ประกอบไปด้วยโปรแกรมต่างๆ ดังนี้
• โปรแกรมป้องกันไวรัสคอมพิวเตอร์
• โปรแกรมไฟร์วอลล์
• โปรแกรมช่วยในการสำรองข้อมูล
• โปรแกรมกู้คืนระบบ กรณีระบบเครือข่ายล่ม
• โปรแกรมเข้าถึงระบบเครือข่ายระยะไกล
• โปรแกรมถอดถอนการติดตั้ง (Uninstall)

## P58 — บทที่ 2 ช่องทางการสื่อสารและส่วนประกอบของเครือข่าย — หัวข้อ ส่วนประกอบเครือข่าย (หน้า 63)

เครื่องลูกข่าย หลังจากที่เครื่องเซิร์ฟเวอร์ได้ทำการติดตั้งเป็นที่เรียบร้อยแล้วเครื่องลูกข่ายต่างๆ ภายในเครือข่ายก็จะถูกติดตั้งตามมา และดำเนินการทดสอบเพื่อเชื่อมโยงเข้ากับเครื่องเซิร์ฟเวอร์ที่เป็นศูนย์บริการ ซึ่งหากการติดตั้งสำเร็จสมบูรณ์ เครื่องลูกข่ายจะต้องสามารถเชื่อมโยงเห็นเครื่องเชิร์ฟเวอร์ หากไม่สามารถเชื่อมโยงระหว่างกันได้ นั่นหมายความว่าเครือข่ายที่ติดตั้งอาจพบข้อผิดพลาดบางประการ ซึ่งอาจเป็นได้ทั้งการติดตั้งค่าคอนฟิกที่ผิด หรือปัญหาด้านอุปกรณ์บางอย่างและสายเคเบิลที่ติดตั้งไม่เรียบร้อย เป็นต้น ดังนั้นจึงจำเป็นต้องค้นหาจุดที่บกพร่องและรีบแก้ไขโดยทันที โดยหลังจากที่เครื่องลูกข่ายสามารถเชื่อมโยงเข้ากับเครื่องเซิร์ฟเวอร์เป็นที่เรียบร้อยแล้ว ขั้นตอนต่อไปก็คือ แอดมินที่ทำหน้าที่บริหารจัดการเครือข่ายจะดำเนินการกำหนดบัญชียูสเซอร์ตามแต่ละแผนก และกำหนดสิทธิการใช้งานบนเครือข่าย โดยเครื่องลูกข่ายสามารถเข้าสู่ระบบเครือข่ายด้วยการล็อกออนเข้าสู่ระบบภายใต้ชื่อบัญชียูสเซอร์ของตน

## P61 — บทที่ 3 รูปแบบการเชื่อมโยงเครือข่ายและระบบเครือข่ายท้องถิ่น — หัวข้อ โปรโตคอลควบคุมการเข้าถึงสื่อกลาง (หน้า 95-96)

กลไกที่ 3 การตรวจจับการชนกัน (Collision Detection) หากภายในสายส่งข้อมูลเกิดเหตุการณ์การชนกันของกลุ่มข้อมูลขึ้น นั่นหมายความว่าข้อมูลที่ส่งไปในขณะนั้นใช้การไม่ได้อีกต่อไป ดังนั้นกลไกของวิธีนี้ก็คือ จะรายงานผลว่ามีการชนกันของกลุ่มข้อมูลขึ้นภายในสายส่ง ครั้นเมื่อเครือข่ายได้รับทราบรายงานแล้ว ก็จะให้เครื่องลูกข่ายที่ส่งข้อมูลในขณะนั้นรอสักครู่หนึ่ง เพื่อสุ่มเวลาในการส่งข้อมูลรอบใหม่บนช่วงเวลาที่แตกต่างกัน ดังนั้นโอกาสที่จะเกิดการชนกันในรอบใหม่จึงลดน้อยลง
รูปที่ 3.19 ได้มีการตรวจจับพบสัญญาณข้อมูลชนกัน ดังนั้นจึงมีการรายงานให้เครือข่ายรับทราบ
รูปที่ 3.20 แต่ละโหนตจะสุ่มเวลาส่งข้อมูลรอบใหม่ เพื่อไม่ให้เกิดการชนกันของข้อมูลอีกโดยจากรูป โหนด A ได้มีการส่งข้อมูลรอบใหม่อย่างสมบูรณ์ โดยปราศจากการชนกันของกลุ่มข้อมูลภายในสายส่ง
