# โครงสร้างข้อมูล

แบ่ง 3 ชั้นตามว่า **ใครสร้าง** และ **หายแล้วกู้คืนยังไง**

```
data/
├── raw/         ดาวน์โหลดมา ห้ามแก้ ห้ามเขียนทับ
├── processed/   ผลผลิตของ pipeline — ตัวนี้คือ dataset ที่เอาไปใช้จริง/ส่งงาน
└── index/       สร้างจาก processed/ ลบทิ้งได้ทุกเมื่อ
```

---

## raw/ — ต้นฉบับ (382 MB)

ดาวน์โหลดจาก Hugging Face ไม่มีการแก้ไขใด ๆ เก็บไว้เพื่อให้ทำซ้ำผลได้และตรวจย้อนได้ว่า
การทำความสะอาดไม่ได้ทำข้อมูลเพี้ยน

| ไฟล์ | ขนาด | ที่มา | เนื้อหา |
|:---|---:|:---|:---|
| `criminal-datasets.csv` | 0.5 MB | `PyThaiNLP/thai-law` release `criminal-csv-v0.1` (สาธารณสมบัติ) | ประมวลกฎหมายอาญา แยกหนึ่งแถวต่อหนึ่งมาตรา ดึงด้วย `scripts/fetch_codes.sh` |
| `civil-and-commercial-datasets.csv` | 1.6 MB | `PyThaiNLP/thai-law` release `civil-commercial-csv-v0.1` (สาธารณสมบัติ) | ประมวลกฎหมายแพ่งและพาณิชย์ รูปแบบเดียวกัน |
| `thailaw_0.parquet` `thailaw_1.parquet` | 181 MB | `pythainlp/thailaw` (CC0) | ตัวบทกฎหมายไทย 42,755 ฉบับ จากเว็บกฤษฎีกา |
| `iapp_0.parquet` `iapp_1.parquet` | 181 MB | `iapp/rag_thai_laws` | ชุดเดียวกัน ทำความสะอาดแล้วโดย iApp — **เป็นตัวที่ pipeline ใช้จริง** |
| `wangchan_train.parquet` `wangchan_test.parquet` | 20 MB | `airesearch/WangchanX-Legal-ThaiCCL-RAG` (MIT) | คู่ถาม-ตอบกฎหมาย 11,954 คู่ ตรวจโดยผู้เชี่ยวชาญ |

ถ้าลบไปแล้วต้องการกลับมา ดาวน์โหลดใหม่จากปลายทาง Parquet ของ Hugging Face
(รายละเอียดอยู่ในภาคผนวก ข ของรายงาน)

## processed/ — ที่เอาไปใช้จริง (110 MB)

สร้างจาก `raw/` ด้วยสคริปต์ใน `ingest/` และ `report/` **นี่คือชุดข้อมูลที่ถือว่าเป็นผลงาน**

| ไฟล์ | ขนาด | จำนวน | สร้างด้วย | ใช้ทำอะไร |
|:---|---:|---:|:---|:---|
| `corpus.jsonl` | 66 MB | 29,485 ชิ้น | `python -m ingest.extract_acts` | **ตัวหลัก** — แชตบอตค้นจากไฟล์นี้ |
| `qa_pairs.jsonl` | 32 MB | 11,953 คู่ | `python -m report.build_doc` | ชุดประเมิน/ฝึกตัวค้นคืน |
| `sections.jsonl` | 1.6 MB | 946 มาตรา | `python -m report.build_doc` | ตัวบท 12 พ.ร.บ. ที่คนใช้บ่อย |
| `corpus_stats.csv` | 17 MB | 42,755 แถว | `python -m report.build_doc` | สถิติรายเอกสารทั้งคลัง |

### corpus.jsonl — หนึ่งบรรทัดต่อหนึ่งมาตรา

| field | ชนิด | ความหมาย | ตัวอย่าง |
|:---|:---|:---|:---|
| `id` | string | คีย์ไม่ซ้ำ `sysid-มาตรา[-ท่อน]` | `642571-118` |
| `act` | string | ชื่อกฎหมาย (ตัดวงเล็บ Update ออก) | `พระราชบัญญัติคุ้มครองแรงงาน พ.ศ. 2541` |
| `act_full` | string | ชื่อเต็มตามต้นฉบับ | `...(ฉบับ Update ล่าสุด)` |
| `sysid` | string | รหัสเอกสารในระบบกฤษฎีกา | `642571` |
| `section` | string | เลขมาตรา เลขอารบิก รองรับ `17/1` | `118` |
| `part` | int | ท่อนที่ กรณีมาตรายาวเกิน 1,800 ตัวอักษร | `0` |
| `text` | string | เนื้อความ ทำความสะอาดแล้ว | `ให้นายจ้างจ่ายค่าชดเชย...` |
| `chapters` | list[string] | รายชื่อหมวดของกฎหมายฉบับนั้น | `["หมวด 1 บททั่วไป", ...]` |
| `n_chars` | int | ความยาวของ `text` | `1702` |

**ขอบเขต** พระราชบัญญัติและพระราชกำหนด **ฉบับล่าสุดของแต่ละฉบับ** 731 ฉบับ
ตัด พ.ร.บ.งบประมาณรายจ่าย (ตารางตัวเลขล้วน) และ พ.ร.บ.แก้ไข `(ฉบับที่ N)` ที่มีฉบับรวมอยู่แล้วออก
บวกประมวลกฎหมายอีก 2 ฉบับที่ผนวกจากคนละแหล่ง — ประมวลกฎหมายแพ่งและพาณิชย์ 1,827 มาตรา
และประมวลกฎหมายอาญา 443 มาตรา ตัดมาตราที่ต้นทางทำเครื่องหมาย `is-cancelled` ออกแล้ว
รวมทั้งสิ้น **733 ฉบับ / 28,928 มาตรา / 29,485 ชิ้น**

ระเบียนของประมวลกฎหมายใช้สคีมาเดียวกับ พ.ร.บ. ทุกประการ ต่างที่ `sysid`
เป็น `code-criminal` หรือ `code-civil` และ `chapters` ว่างเปล่า เพราะต้นทางไม่ได้ให้โครงบรรพมาด้วย

### qa_pairs.jsonl — หนึ่งบรรทัดต่อหนึ่งคู่ถาม-ตอบ

| field | ชนิด | ความหมาย |
|:---|:---|:---|
| `split` | string | `train` (8,211) หรือ `test` (3,742) |
| `question` | string | คำถาม |
| `answer` | string | คำตอบที่ถูก ตรวจโดยผู้เชี่ยวชาญ |
| `wrong_answer` | string | คำตอบที่ผิด เกิดจากใช้บริบทผิด — ใช้ทดสอบว่าโมเดลรู้ตัวไหม |
| `laws` | list[string] | ชื่อกฎหมายที่อ้าง |
| `sections` | list[string] | มาตราที่อ้าง เช่น `ประมวลรัษฎากร มาตรา 3` |
| `n_pos` / `n_neg` | int | จำนวนบริบทเชิงบวก / เชิงลบยาก |

**ข้อจำกัดที่ต้องรู้** ครอบคลุมกฎหมาย 35 ฉบับ และเอนไปทางกฎหมายธุรกิจ-ตลาดทุนอย่างหนัก
ไม่มีคำถามด้านแรงงาน ครอบครัว มรดก หรือเช่าที่อยู่อาศัยเลย ใช้ฝึก/ประเมินตัวค้นคืนได้ดี
แต่ใช้ประเมินแชตบอตสำหรับประชาชนไม่ได้

### sections.jsonl — เหมือน corpus.jsonl แต่จำกัด 12 พ.ร.บ.

field `law` `law_full` `domain` `sysid` `section` `text` `n_chars` — ใช้เป็นชุดตัวอย่างขนาดเล็ก

### corpus_stats.csv

`sysid, title, doc_type, year, n_chars` — หนึ่งแถวต่อหนึ่งเอกสารในคลังทั้ง 42,755 ฉบับ
ใช้ทำสถิติในบทที่ 4 ของรายงาน

## index/ — สร้างใหม่ได้ (83 MB)

| ไฟล์ | ขนาด | คืออะไร |
|:---|---:|:---|
| `bm25.pkl` | 30 MB | ดัชนี BM25 ตัดคำด้วย pythainlp newmm |
| `vectors.npy` | 53 MB | เวกเตอร์ BGE-M3 float16 ขนาด (27218, 1024) |

สร้างใหม่ด้วย `python -m ingest.build_index` (BM25 ~15 วินาที, dense ~20-40 นาทีบน Mac)
**ลำดับแถวต้องตรงกับ `corpus.jsonl` เป๊ะ ๆ** ถ้าแก้ corpus แล้วไม่ rebuild ระบบจะโยน
`index/corpus mismatch` ตอนเริ่มทำงาน ไม่ปล่อยให้ตอบผิดเงียบ ๆ

---

## ทำซ้ำทั้งหมดจากศูนย์

```bash
python -m ingest.extract_acts    # raw/ -> processed/corpus.jsonl
python -m ingest.build_index     # processed/ -> index/
python -m report.build_doc       # raw/ -> processed/*.jsonl + report/*.md
```
