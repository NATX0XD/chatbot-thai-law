# โครงสร้างข้อมูล

แบ่ง 3 ชั้นตามว่า **ใครสร้าง** และ **หายแล้วกู้คืนยังไง**

```
data/
├── raw/         ดาวน์โหลดมา ห้ามแก้ ห้ามเขียนทับ
├── ocr/         ผล OCR ของ PDF ที่ text layer ใช้ไม่ได้ — commit ไว้ กู้ยากถ้าหาย
├── eval/        ชุดประเมินเขียนมือ — commit ไว้ ทำซ้ำอัตโนมัติไม่ได้
├── processed/   ผลผลิตของ pipeline — ตัวนี้คือ dataset ที่เอาไปใช้จริง/ส่งงาน
└── index/       สร้างจาก processed/ ลบทิ้งได้ทุกเมื่อ
```

**คลังที่ใช้อยู่ตอนนี้คือจรรยาบรรณวิชาชีพครู** (`processed/corpus_ksp.jsonl`)
คลังกฎหมายทั่วไปชุดเดิม (`processed/corpus.jsonl`) ยังอยู่ครบและสลับกลับได้ด้วย
`CORPUS_FILE` เอกสารนี้อธิบายทั้งสองชุด ชุดใหม่ก่อน

---

## raw/ksp/ — ต้นฉบับชุดที่ใช้อยู่ (2.1 MB)

PDF 10 ฉบับจาก https://www.ksp.or.th/laws/ ดึงด้วย `scripts/fetch_ksp.sh`
ซึ่งตรึง sha256 ไว้ทุกไฟล์ checksum ไม่ตรงแปลว่าต้นทางเปลี่ยนเอกสาร ให้ดูว่าเปลี่ยนอะไร
ก่อนแก้ค่าในสคริปต์ เพราะเลขข้ออาจขยับตามไปด้วย

เอกสารเก้าฉบับแรกคือหมวด "จรรยาบรรณวิชาชีพ" ทั้งหมวด ฉบับที่สิบคือพระราชบัญญัติแม่บท
เอกสารที่ **ไม่** ดึงโดยตั้งใจคือ `EthicTeacher.pdf` (e-book 56 หน้า 76 MB เป็นภาพสแกนล้วน
เนื้อหาซ้ำกับข้อบังคับ 2556 และ 2550) และเอกสารอีกราว 105 ฉบับในหน้า `laws/`
ที่ไม่เกี่ยวกับจรรยาบรรณ

## ocr/ — ผลอ่านภาพ commit ไว้ (86 KB)

PDF สี่ฉบับใช้ฟอนต์ subset ที่ cmap ถูกตัดทิ้ง หรือวางกลิฟความกว้างศูนย์ผิดตำแหน่ง
text layer จึงกู้ไม่ได้เลย ต้องเรนเดอร์เป็นภาพแล้วอ่านด้วย **Vision framework ของ macOS**

ไม่ใช่ tesseract โดยตั้งใจ — tesseract อ่านตัวอักษรพอได้แต่อ่านเลขไทยผิดเป็นระบบ
บนข้อบังคับฯ 2568 มันอ่าน ข้อ ๑..๙ เป็น 1 2 3 5 5 2 3 5 5 ทุกการอ้างอิงของบอทคือตัวเลข

ผลถูก cache เป็นไฟล์ข้อความและ commit ลง repo เพราะทำซ้ำได้เฉพาะบน macOS
เครื่องอื่นจึงสร้างดัชนีต่อได้โดยไม่ต้องมี Vision ลบไฟล์ในนี้ถ้าต้องการให้อ่านใหม่

**ข้อจำกัด** คำเพี้ยนระดับตัวอักษรราว 0.8% ของคำหลัก (เช่น "กล่าวไทษ" 2 จุดจาก 263)
เลขข้อและเลขมาตราถูกต้องทั้งหมด ซึ่งเป็นส่วนที่กระทบการอ้างอิง

## eval/ — ชุดประเมินเขียนมือ

`ksp_questions.jsonl` 65 บรรทัด หนึ่งบรรทัดต่อหนึ่งคำถาม

| field | ความหมาย |
|:---|:---|
| `id` | `EV-001` |
| `question` | คำถาม |
| `expect` | `answer` หรือ `refuse` |
| `category` | หนึ่งในห้าด้าน หรือ `กระบวนการ` `นอกโดเมน` `ไม่ใช่คำถามกฎหมาย` |
| `gold_ids` | รายการ `sysid:section` ที่ต้องค้นเจอ ว่างสำหรับข้อที่ต้องปฏิเสธ |

ขับทั้ง `ingest/calibrate.py` (เลือกเกณฑ์ cosine) และ `ingest/tune_fusion.py` (เลือกน้ำหนัก)
ทั้งสองสคริปต์ไม่มีรายการคำถามของตัวเองแล้ว เพิ่มคำถามคือแก้ข้อมูล ไม่ใช่แก้สคริปต์

**ข้อจำกัด** เขียนโดยผู้สร้างระบบเอง 65 ข้อเล็กเกินกว่าจะอ้างเป็นผลวัดเชิงสถิติ
ใช้ตั้งเกณฑ์และจับการถดถอยได้ การตัดสินคุณภาพคำตอบอยู่ที่ `docs/ksp-acceptance-tests.md`
ซึ่ง agent คนละตัวเป็นผู้ตรวจ

## processed/corpus_ksp.jsonl — ตัวหลักที่แชตบอตค้น

334 ชิ้น จาก 324 ข้อและมาตรา สร้างด้วย `python -m ingest.extract_ksp`

ใช้ field เดิมของ `corpus.jsonl` ทุกตัว (`id` `act` `act_full` `sysid` `section` `part`
`text` `chapters` `n_chars`) แล้วเติมของใหม่หกตัว

| field | ชนิด | ความหมาย | ตัวอย่าง |
|:---|:---|:---|:---|
| `unit` | string | `"ข้อ"` หรือ `"มาตรา"` | `ข้อ` |
| `short` | string | ชื่อย่อทางการ ที่คำตอบต้องคัดลอกไปใช้ | `ข้อบังคับคุรุสภา จรรยาบรรณของวิชาชีพ 2556` |
| `ethics_category` | string หรือ null | หนึ่งในห้าด้าน | `ต่อตนเอง` |
| `superseded_by` | string หรือ null | คีย์ของฉบับที่มายกเลิก | `ksp-2568` |
| `source_url` | string | ลิงก์ PDF ต้นทาง | `https://ratchakitcha.soc.go.th/documents/1986083.pdf` |
| `published` | string | วันประกาศราชกิจจาฯ `YYYY-MM-DD` พ.ศ. | `2556-10-04` |

`unit` จำเป็นเพราะข้อบังคับคุรุสภานับเป็น "ข้อ" ส่วนพระราชบัญญัตินับเป็น "มาตรา"
เขียนว่า "ข้อบังคับคุรุสภา มาตรา 7" คือชี้ไปยังสิ่งที่ไม่มีอยู่จริง และเป็นรูปแบบที่ผู้อ่าน
จะถือไปโต้แย้งกับคุรุสภา

`short` มีเพราะชื่อเต็มยาวแปดสิบตัวอักษร ถ้าไม่ให้ชื่อย่อไป โมเดลจะย่อเอง และเคยย่อ
ข้อบังคับฯ แบบแผนพฤติกรรม 2550 เป็น "ข้อบังคับฯ จรรยาบรรณ 2550" ซึ่งเป็นชื่อของคนละฉบับ

`ethics_category` เติมจากหัวหมวดของเอกสาร ไม่ใช่เดาจากเนื้อความ มีเฉพาะสองฉบับที่มี
โครงหมวดแบบนี้ — 2556 ระบุห้าด้านเป็น หมวด 1–5 ส่วน 2550 ระบุซ้ำเป็น ส่วนที่ 1–5
ในทุกหมวดของผู้ประกอบวิชาชีพสี่ประเภท เอกสารที่เหลือเป็น `null`

`superseded_by` เป็นข้อเท็จจริงจากตัวบท — ข้อ 3 ของข้อบังคับฯ 2568 ยกเลิกฉบับ 2553
และฉบับแก้ไขทั้งสองอย่างชัดแจ้ง ทั้งสามฉบับยังอยู่ในดัชนีเพราะฉบับ 2568 อ้างถึงเรื่อง
ที่เริ่มดำเนินการไว้ตามฉบับเดิม แต่ถูกลดคะแนนจัดอันดับและติดป้าย "(ยกเลิกแล้ว)" ใน citation

### corpus_ksp_audit.md — รายงานตรวจความสมบูรณ์

สร้างด้วย `python -m ingest.audit_ksp` ตรวจหกเรื่องที่เทสต์ตรวจไม่ได้ เพราะไม่มีเทสต์ไหน
รู้ว่าเอกสารมีกี่ข้อ — เลขข้อเรียงครบ, จำนวนตรงกับที่นับจาก PDF ด้วยมือ, ห้าด้านครบและ
ติดป้ายถูกหมวด, ไม่มีข้อความหาย, ไม่มีหัวกระดาษราชกิจจาฯ ปน, และตัวบทห้าด้านพูดถึงด้านนั้นจริง

ตัวเลขล่าสุด: เก็บอักษรไทยของตัวบทไว้ 89–97% ต่อฉบับ วัดจากช่วง ข้อ ๑ ถึงบล็อกลงนาม
ส่วนคำปรารภและแบบฟอร์มท้ายเล่มถูกตัดทิ้งโดยตั้งใจ

### corpus.jsonl — หนึ่งบรรทัดต่อหนึ่งมาตรา

| field | ชนิด | ความหมาย | ตัวอย่าง |
|:---|:---|:---|:---|
| `id` | string | คีย์ไม่ซ้ำ `sysid-มาตรา[-ท่อน]` | `642571-118` |
| `act` | string | ชื่อกฎหมาย (ตัดวงเล็บ Update ออก) | `พระราชบัญญัติคุ้มครองแรงงาน พ.ศ. 2541` |
| `act_full` | string | ชื่อเต็มตามต้นฉบับ | `...(ฉบับ Update ล่าสุด)` |
| `sysid` | string | รหัสเอกสารในระบบกฤษฎีกา | `642571` |
| `section` | string | เลขมาตรา เลขอารบิก รองรับ `17/1` | `118` |
| `part` | int | ท่อนที่ กรณีมาตรายาวเกิน 1,800 ตัวอักษร | `0` |
| `text` | string | เนื้อความ ทำความสะอาดแล้ว | `ให้นายจ้างจ่ายค่าชดเชย...` |
| `chapters` | list[string] | รายชื่อหมวดของกฎหมายฉบับนั้น | `["หมวด 1 บททั่วไป", ...]` |
| `n_chars` | int | ความยาวของ `text` | `1702` |

**ขอบเขต** พระราชบัญญัติและพระราชกำหนด **ฉบับล่าสุดของแต่ละฉบับ** 731 ฉบับ
ตัด พ.ร.บ.งบประมาณรายจ่าย (ตารางตัวเลขล้วน) และ พ.ร.บ.แก้ไข `(ฉบับที่ N)` ที่มีฉบับรวมอยู่แล้วออก
บวกประมวลกฎหมายอีก 2 ฉบับที่ผนวกจากคนละแหล่ง — ประมวลกฎหมายแพ่งและพาณิชย์ 1,827 มาตรา
และประมวลกฎหมายอาญา 443 มาตรา ตัดมาตราที่ต้นทางทำเครื่องหมาย `is-cancelled` ออกแล้ว
รวมทั้งสิ้น **733 ฉบับ / 28,928 มาตรา / 29,485 ชิ้น**

ระเบียนของประมวลกฎหมายใช้สคีมาเดียวกับ พ.ร.บ. ทุกประการ ต่างที่ `sysid`
เป็น `code-criminal` หรือ `code-civil` และ `chapters` ว่างเปล่า เพราะต้นทางไม่ได้ให้โครงบรรพมาด้วย

## index/ — สร้างใหม่ได้ (83 MB)

|:---|---:|:---|

## ทำซ้ำทั้งหมดจากศูนย์

คลังที่ใช้อยู่ (จรรยาบรรณวิชาชีพครู)

```bash
./scripts/fetch_ksp.sh           # -> raw/ksp/*.pdf  ตรวจ checksum
python -m ingest.extract_ksp     # raw/ksp/ -> processed/corpus_ksp.jsonl
python -m ingest.audit_ksp       # ตรวจ 6 ด่าน ต้องผ่านครบก่อนไปต่อ
python -m ingest.build_index     # processed/ -> index/   (~15 วินาที)
```
